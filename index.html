PROJECT 04 · FEATURED

크라임씬

AI가 매번 새로운 사건과 용의자 3명을 만들고, 채팅으로 용의자를 심문해 범인을 찾는 추리 게임

Demo Code
PythonStreamlitClaude API · Haiku
자세히 보기

주요 기능

  • 사건 생성 — 난이도(쉬움 20회 · 보통 15회 · 어려움 10회 질문)와 배경(저택, 학교, 회사, 병원, 호텔, 우주정거장)을 고르면 사건 개요, 용의자 3명, 범인, 핵심 단서가 JSON으로 생성됩니다.
  • 용의자 심문 — 용의자마다 성격, 알리바이, 비밀이 달라 같은 질문에도 다른 답이 나오고, 범인은 거짓말을 섞어 답합니다.
  • 수사 노트 — 용의자별 진술이 사이드바에 자동 기록되고, 남은 질문 횟수와 메모장이 함께 표시됩니다.
  • 최종 추리 — 범인과 근거를 제출하면 AI가 추리를 평가하고 사건의 진상을 이야기 형태로 해설합니다.

만든 이유

AI API를 단순한 Q&A 챗봇으로만 쓰지 않고, 역할극과 구조화된 JSON 출력까지 한 프로젝트에서 써보고 싶었습니다. 추리 게임은 용의자마다 숨기는 정보가 달라서 프롬프트 설계의 차이가 결과에 바로 드러납니다.

배운 점

  • AI가 만든 JSON을 그대로 믿으면 안 되고, 파싱·검증 단계가 필요하다는 것
  • 역할, 말투, 답변 길이를 프롬프트에 구체적으로 적어야 캐릭터가 유지된다는 것
  • Streamlit은 매번 다시 실행되므로 상태를 st.session_state로 관리해야 한다는 것
  • API 키는 환경변수로 분리해야 안전하게 배포할 수 있다는 것

어려웠던 점 → 해결

  • JSON 형식이 어긋나거나 잘림 → 첫/마지막 중괄호 사이만 파싱, 필수 항목 검증 후 실패 시 재생성, 토큰 한도 3000
  • 답변 앞에 이름 접두사가 붙어 몰입이 깨짐 → 정규식으로 제거, 최근 대화 10개만 전달
  • 대화창과 입력창이 떨어져 보임 → 하나의 st.container 안에 함께 배치

취향평론가

Last.fm 청취 기록을 바탕으로 Claude가 음악 평론가처럼 내 취향을 리뷰하고 음악을 추천해 주는 웹 서비스

Demo Code

프로젝트 소개

Last.fm API로 많이 들은 아티스트와 곡, 최근 청취 기록을 불러오고, Claude API가 이 데이터를 바탕으로 "나는 어떤 음악을 듣는 사람인지"를 평론가의 글로 풀어준 뒤 다음에 들을 만한 음악까지 추천합니다.

만든 이유

음악 앱의 연말 결산은 순위만 보여줄 뿐, 내가 왜 이런 음악을 좋아하는지나 취향이 어떻게 바뀌었는지는 알려주지 않습니다. 처음엔 Spotify API를 쓰려 했지만 새 앱은 제한이 많아, 청취 기록을 자유롭게 불러올 수 있는 Last.fm API를 선택했습니다.

배운 점

GitHub MCP와 바이브 코딩으로 Open API와 연동하는 법을 배웠습니다.

어려웠던 점 → 해결

배포하는 데 20분이 걸렸습니다 → Claude CLI를 설치해 Claude Code를 활용했습니다.
